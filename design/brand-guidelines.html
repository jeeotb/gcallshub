10 · Bàn giao

Đưa vào Figma và code

  1. Token màu, chữ, khoảng cách: mở file design/gcalls-tokens.json trong repo. Trong Figma: bảng Variables, chọn Import (định dạng W3C Design Tokens), hoặc dùng plugin Tokens Studio → Load from file.
  2. Logo, icon, ảnh 3D: kéo thư mục design/assets/ vào Figma. SVG giữ được vector, chỉnh màu được.
  3. Màn hình: dùng plugin html.to.design, dán link trang prototype (mỗi màn một link viewer.html?s=Main&bare=1) để lấy layer chỉnh sửa được. Hoặc kéo ảnh trong docs/screens/ làm tham chiếu.
  4. Dev: token cũng dùng trực tiếp được trong code (Style Dictionary sinh ra Swift, Kotlin, CSS). Đặc tả đầy đủ ở docs/SPEC.md.
